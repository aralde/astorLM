In-tab agent demo

The agent loop, the tool calls and the sandboxed execution all run in this tab, using the astorlm/browser entry point. Files live in memory and code runs in QuickJS compiled to WASM, with no filesystem, network or imports.

Your key never leaves the browser. It is sent only to the endpoint you enter, straight from this page, and is not stored. There is no backend. The endpoint must allow cross-origin requests (CORS) from this origin; otherwise the browser blocks the call. Many hosted APIs do not, so enable CORS on your side, or use a local server such as Ollama with OLLAMA_ORIGINS set. The model must support tool calling.
